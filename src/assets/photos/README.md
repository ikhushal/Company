# Photos

Put licensed photographs here, for example `hero.jpg`, and reference them in `site.config.json` under `photos`.

- A configured photo is used only if its file exists, so the site never shows a broken image.
- Recommended: JPG, 2000 px wide, under 400 KB.
- Record the source and licence of every photo in `docs/phase-1-reconciliation.md` (section 6).
- Never caption or present a stock photo as a Whitestone project.

This README is not copied into the built site.
